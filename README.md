# آمار ۰٫۵٫۰ برای Windows 10/11 x64

[دانلود مستقیم بستهٔ کامل ویندوز](https://github.com/davidkordmir-source/AMAR/raw/refs/heads/downloads/windows-v0.5.0/downloads/AMAR-Windows-x64-v0.5.0.zip)

[فایل SHA256](downloads/AMAR-Windows-x64-v0.5.0.sha256)

ZIP را کامل با Extract All باز کنید و AMAR.exe را اجرا کنید. پایتون، کتابخانه‌ها و موتور خواندن اسکن فارسی/انگلیسی همراه آن است؛ نصب جداگانه و اینترنت برای اجرا لازم نیست. بالای صفحه باید نسخهٔ **۰٫۵٫۰** دیده شود.

در این نسخه:

- قرارداد، تخصیص وجه، سند مالی، درخواست‌های قطعه/انتقال/اصلاح/شمارش/پرداخت و مدارک اسکن گزینه‌های ویرایش و حذف مشروط دارند. پرداخت و گردش قطعی از سابقه پاک نمی‌شود؛ علتِ ممنوعیت حذف نمایش داده می‌شود. اصلاحات دارای دلیل و سابقه‌اند.
- PDF، PNG و JPEG آفلاین خوانده می‌شوند. تصویر سند و پیشنهاد شماره/مبلغ/تاریخ برای بررسی شما نمایش داده می‌شود. تأیید اسکن به‌تنهایی دریافت یا پرداخت ایجاد نمی‌کند؛ تکمیل فرم و تأیید مستقل پرداخت همچنان لازم است.
- گزارش‌ها و ساختار موقعیت‌ها جست‌وجو و صفحه‌بندی دارند؛ انتخاب کالا و انبار با جست‌وجوی محلی انجام می‌شود. آخرین گزارش هر نصب مستقل نمایه می‌شود و ورود چند فایل به‌ترتیب ممکن است.
- ساختار به ۳۰ کارخانه محدود نیست. آزمون مصنوعی با ۱۰۰۰ زیرمجموعه، یک میلیون گردش انبار و ۱۰۰۰ مبدأ مستقل انجام شده است؛ این آزمون، تأیید استفادهٔ هم‌زمان در هزار کارخانه نیست.
- دکمهٔ «بستن برنامه» داخل رابط برای حساب ارشد اضافه شده است. × پنجرهٔ کنترل ویندوز هم برنامه را می‌بندد.
- عنوان‌های «اطلاعات پایه»، «تبادلات اطلاعات» و «موقعیت»، منوی بدون زیرمنو، نام نرم‌افزار و سمت‌های قابل تغییر، زیرانبارهای چندسطحی و ترتیب «اعتبار ← تخصیص وجه ← ثبت پرداخت» حفظ شده‌اند.
- پشتیبان جدید همهٔ نسخه‌های اسکن را هم نگه می‌دارد. ارتقا از دادهٔ نمایشی ۰٫۴٫۱ با حفظ مانده‌ها، اسناد و هویت نصب بررسی شده است.

اگر نسخهٔ قدیمی باز است، اجرای جدید تلاش می‌کند پنجرهٔ کنترلِ مربوط به همان پوشهٔ داده را جلو بیاورد؛ آن را با × ببندید. اگر نسخهٔ قبلی خروج ندارد و پنجره‌اش پیدا نشد، کارهای باز را ذخیره کنید، ویندوز را Restart کنید و سپس AMAR.exe پوشهٔ جدید را اجرا کنید. بستن مرورگر به‌تنهایی کافی نیست. پوشهٔ دادهٔ `%LOCALAPPDATA%\AMAR` را پاک نکنید.

مجوزهای تازهٔ ویرایش/حذف/اسکن را حساب ارشد می‌تواند در «نام‌ها، افراد و نقش‌ها» واگذار کند؛ نقش‌های سفارشی قبلی خودکار گسترده نمی‌شوند. هر موقعیت مستقل است و گزارش امضاشده با فایل منتقل می‌شود؛ آمار دریافتی زمان‌دار و خواندنی است. اطلاعات بالادست فقط با محدوده و مجوز صریح قرارداد در دسترس قرار می‌گیرد.

بررسی بسته با Python ویندوز و Wine شامل مجموعهٔ آزمون‌ها، پنجرهٔ بومی، خواندن اسکن فارسی، تصویر سند، تأیید انسانی، ثبت مالی و خروج از رابط است. پیش از ثبت اطلاعات واقعی، پذیرش روی رایانهٔ ویندوز کارخانه و بازیابی پشتیبان را انجام دهید. این نسخه ضمانت «بدون باگ» یا حسابداری دوبل قانونی ندارد.

راهنمای کامل شرایط و حدود قابلیت‌ها در Windows-Guide.html و README-Windows.md داخل ZIP است. این شاخه فقط بستهٔ دانلود و راهنما را نگهداری می‌کند.
