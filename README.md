# کارگاه سازندهٔ آمار — اصلاحیهٔ ورود Fix 1

پس از Extract All، در پوشهٔ **AMAR-Maker-Fix1** فایل **Start-Maker.cmd** را اجرا کنید.
درخواست ورود تازه را از برنامهٔ شرکت بگیرید و فایل AMAR-Developer-Challenge.json را انتخاب کنید.
اگر کلید هنوز فعال نیست، همین ابزار رمز دانلود کارگاه را می‌پرسد، کلید را در همین پوشه باز می‌کند و مجوز ورود را می‌سازد. فعال‌سازی جداگانه لازم نیست.

رمز همان رمز خصوصی دانلود قبلی است و در گیت‌هاب قرار ندارد. کلید در بسته با AES-256-GCM و scrypt رمزگذاری شده است؛ کارگاه فعال‌شده و رمز را خصوصی نگه دارید.

این اصلاحیه پیام گمراه‌کنندهٔ «بازیابی از پشتیبان» برای کارگاه رمزگذاری‌شده را اصلاح می‌کند. خطاهای رمز، فایل ناقص، کلید نامرتبط و نداشتن دسترسی ذخیره پیام‌های جدا دارند. فایل publisher/private/last-access-status.txt مسیر همین کارگاه و وضعیت آخر را نشان می‌دهد و رمز، کلید یا مجوز را ندارد.

۸ آزمون روی میزبان و در Python 3.13.17 ویندوز زیر Wine موفق بودند. اجرای مسیر تعاملی بدون فعال‌سازی قبلی، رد رمز اشتباه و تلاش دوباره، مسیر فارسی دارای فاصله، مستقل‌بودن از پوشهٔ جاری و مطابقت مجوز با هویت نسخهٔ نصبی نیز بررسی شدند.
