# آمار ۰٫۶٫۰ — نسخهٔ نصبی ویندوز

فایل نصب کامل Windows 10/11 x64 در پوشهٔ `output` قرار دارد. پایتون، خواندن اسکن فارسی/انگلیسی و همهٔ وابستگی‌های اجرا همراه نصب‌اند و برنامه برای اجرا به اینترنت نیاز ندارد.

- فایل نصب: `output/AMAR-Setup-v0.6.0-x64.exe`
- راهنمای نصب و شخصی‌سازی: `output/AMAR-Install-and-Branding-v0.6.0-fa.pdf`
- کنترل صحت فایل‌ها: `output/SHA256SUMS.txt`

با حساب مالک اصلی نصب، «استودیوی اختصاصی مالک» برای تغییر نام، لوگو، رنگ و نمای برنامه در دسترس است. پیش از ارتقا پشتیبان بگیرید و برنامه را کامل ببندید. نصب مجدد و حذف برنامه، داده‌های کارخانه یا مسیر اختصاصی AMAR_DATA_DIR را پاک نمی‌کنند.

تمام ۱۷۶ آزمون با پایتون واقعی ویندوز در Wine موفق بودند؛ نصب، ارتقا و حذف نیز با دادهٔ ساختگی بررسی شدند. پذیرش نهایی روی ویندوز کارخانه لازم است. فایل اجرایی گواهی تجاری Authenticode ندارد.
