# AMAR — دانلود نسخهٔ ویندوز

[دانلود مستقیم بستهٔ ویندوز ۶۴ بیتی](downloads/AMAR-Windows-x64.zip?raw=true)

ویژهٔ Windows 10/11 x64؛ پایتون و کتابخانه‌ها همراه بسته‌اند و استفاده به اینترنت نیاز ندارد.

۱. ZIP را با Extract All کامل باز کنید.
۲. روی AMAR.exe دوبار کلیک کنید.
۳. در اجرای نخست حساب مدیر را بسازید. راهنمای فارسی در Windows-Guide.html داخل بسته است.

[فایل SHA256 برای بررسی صحت دانلود](downloads/AMAR-Windows-x64.sha256)

این نسخه برای پایلوت است. ۴۸ آزمون و بررسی پنجرهٔ ویندوز در Wine موفق بوده‌اند؛ آزمون پذیرش روی ویندوز واقعی کارخانه هنوز لازم است. فایل اجرایی امضای تجاری Authenticode ندارد.
