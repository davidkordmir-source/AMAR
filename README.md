# راهنمای سادهٔ کاربر آمار — نسخهٔ ۰٫۵٫۰

[دانلود مستقیم راهنمای فارسی (PDF)](https://github.com/davidkordmir-source/AMAR/raw/refs/heads/downloads/user-guide-v0.5.0/downloads/AMAR-User-Guide-v0.5.0-fa.pdf)

راهنمای ۱۶ صفحه‌ای با فهرست قابل کلیک، متن فارسی و فونت‌های همراه فایل؛ قابل مطالعه و چاپ در اندازهٔ A4.

شامل اولین ورود، تعریف مجموعه و موقعیت، نام‌ها و دسترسی‌ها، انبار و قطعات، قرارداد، اعتبار و پرداخت، مثال کامل خرید و تحویل، مصرف و برگشت، انتقال و انبارگردانی، اسکن با تأیید انسانی، ویرایش و حذف مشروط، گزارش و تبادل فایل، پشتیبان و رفع مشکلات رایج است.

مثال‌ها فرضی‌اند. نام گزینه‌ها و مراحل با نسخهٔ ۰٫۵٫۰ تطبیق داده شده‌اند. این شاخه فقط راهنما و فایل بررسی صحت آن را نگهداری می‌کند.
