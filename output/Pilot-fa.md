# پذیرش دو موقعیت پیش از استفادهٔ سراسری · ۰٫۸٫۰

این سناریو ابتدا با اطلاعات نمونه در دو نصب مستقل ویندوز انجام شود. اطلاعات واقعی یا پایگاه کامل مرکز را به موقعیت محدود منتقل نکنید. آزمون خودکار دو هویت مستقل و ظرفیت ۱۰۰۰ زیرمجموعه انجام شده؛ این برگه برای بررسی رایانه‌ها، روال‌ها و اشخاص واقعی شماست.

| کار | نتیجهٔ قابل بررسی |
|---|---|
| پشتیبان‌گیری و نصب نسخهٔ جدید | حساب، عنوان، ظاهر، اسکن‌ها و مانده‌های قبلی حفظ و نسخهٔ ۰٫۸٫۰ دیده شود. |
| تعریف مرکز، شهر و دو کارخانه | فرد کارخانهٔ اول، کارخانهٔ دوم و قرارداد بدون مجوز را نبیند؛ حساب ارشد ببیند. |
| قرارداد سه دستگاه با دو تأیید | یک رأی قرارداد را قطعی نکند؛ رأی ثبت‌کننده رد شود؛ دومین تأیید تعهد بسازد و موجودی واقعی ثابت باشد. |
| تخصیص و درخواست پرداخت | تا آخرین تأیید حساب کم نشود؛ کلیک تکراری سند اضافه نسازد. |
| تحویل با الزام کیفیت | موجودی قبل از پذیرش ثابت و پس از تأیید مستقل فقط یک بار افزایش یابد. |
| اسکن بارکد و سریال | شناسنامه، محل، گردش و سفارش باقی‌مانده فقط در محدودهٔ مجاز دیده شود. |
| تعمیر با تحویل دو قطعه | تا مصرف یا برگشت کامل و تأیید مستقل بسته نشود؛ موعد سرویس بعدی جلو رود. |
| انبارگردانی دوره‌ای | گردش پس از شمارش، اعمال شمارش قدیمی را مسدود کند؛ شمارش تازه مستقل تأیید شود. |
| برگشت کامل پرداخت | اصل سند بماند؛ برگشت جدا ثبت و مانده‌ها درست شوند؛ حذف قرارداد همچنان مسدود باشد. |
| بستن دورهٔ مالی | دریافت، پرداخت، تغییر اعتبار و تخصیص رد شوند؛ بازگشایی علت داشته باشد. |
| تبادل هویت و بستهٔ رمزگذاری‌شده | فایل فقط در نصب گیرنده باز شود؛ قرارداد بدون مجوز در بسته نباشد. |
| پذیرش بسته و رسید برگشتی | پس از ورود رسید ارسال بعدی ممکن شود؛ تکرار فایل، دفتر محلی را تکرار نکند. |
| تغییر اطلاعات و بستهٔ بعدی | فقط گزارش همان مبدأ تازه شود؛ فایل قدیمی جای جدید ننشیند؛ تعارض بررسی بخواهد. |
| پیگیری هشدار | مسئول، موعد و نتیجه ثبت شود؛ تغییر منشأ نیاز به بررسی تازه را نشان دهد. |
| کارگاه سازنده | کلید قبلی وارد، رمز چسبانده، مجوز تازه ساخته و ورود مستقل انجام شود؛ مدیرعامل نتواند هویت را ویرایش کند. |
| ساخت و نصب هویت اختصاصی | نام EXE، آیکن و خروجی output درست و حساب‌های قبلی پس از نصب محفوظ باشند. |
| بستن و بازیابی پشتیبان | برنامه کامل بسته شود؛ در پوشهٔ آزمایشی تازه، اسکن‌ها و هویت تبادل بازیابی شوند. |

برای هر مورد تاریخ، شخص اجراکننده، نتیجه و شرح مغایرت را ثبت کنید. ماندهٔ مالی و موجودی را با اسناد نمونه مقایسه و مغایرت را تعیین تکلیف کنید. دریافت فایل در این نسخه، گزارش خواندنی مبدأ است؛ دفاتر هر نصب مستقل می‌مانند. برگشت پرداخت کامل است؛ برگشت جزئی هنوز وجود ندارد.
